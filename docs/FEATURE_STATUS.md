# VELTRIX feature status

The Module Manager intentionally distinguishes integration levels instead of presenting unavailable functions as already working.

| Module | Current implementation state |
|---|---|
| Music Island | Android media-session metadata + play/pause/next via Notification Listener |
| Notification Island | Basic title/text banner via Notification Listener |
| Battery Intelligence | Battery percentage and charging state in overlay |
| Adzan Reminder | Prayer alert notification, Accept action, optional user-selected audio |
| Prayer Schedule | Location/manual coordinates + AlAdhan KEMENAG method 20 timings |
| Live Lyrics | User-imported LRC, playback-position synchronization |
| Weather Island | Provider integration required |
| Timer & Stopwatch | UI/control integration required |
| Clipboard Island | Clipboard handler required |
| Navigation Island | Supported notification/provider integration required |
| Live Score | Live data provider required |
| Quick Tools | Dedicated tools screen required |
| Bluetooth Connect | Device/profile signal integration required |
| Focus Mode | Session engine required |
| Pomodoro | Timer engine required |
| Screen Activity | Platform-scoped detection only; global detection is not available to ordinary apps |
| App Launch | Shortcut surface required |
| Volume HUD | Platform/OEM signal integration required |
| Network Monitor | Network statistics surface required |
| Data Monitor | Usage-statistics access and UI required |
| Mini Notes | Local notes store and editor required |
| QR Scanner | Camera permission and scanner screen required |
| Device Temperature | Thermal status integration required |
